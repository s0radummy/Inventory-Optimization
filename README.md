# 🏪 Inventory KPI Dashboard  

## 📌 Project Overview  
This project focuses on analyzing inventory performance for a retail dataset with **109,501 records**.  
The objective is to monitor **inventory efficiency**, identify stockout risks, and provide actionable insights using SQL queries and interactive dashboards.  

---

## 🔑 Key Features  
- **SQL-driven KPI Calculation**  
  - Stockout Rate (by Store, Product, Category, Region)  
  - Average Inventory Level  
- **Data Visualization with Streamlit + Plotly**  
  - Interactive charts and tables for exploring inventory trends  
  - Filters by product, store, and category  
- **Relational Schema (ERD Design)**  
  - Structured tables for Products, Stores, Sales, and Inventory  
  - Supports scalability for forecasting extensions  

---

## 📂 Tech Stack  
- **Python**: Data processing & dashboard  
- **Pandas**: Data wrangling  
- **SQL**: KPI generation & analytics  
- **Streamlit**: Dashboard UI  
- **Plotly**: Interactive visualizations
